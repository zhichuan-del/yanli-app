# 日程与跟进工作流

- 正文使用白色实底；菜单保留薄雾玻璃。记录分开显示标题、日期分类和两行正文摘要，交流详情可展开阅读完整正文及操作跟进。
- 选日日程按未完成计划、进展、交流、已完成计划分组；计划内部按高、中、低优先级。所选日显示三类数量，月历显示真实总条数并保留类别点，连续月份保持懒加载。
- 新建先输入标题和内容，日期与分类折叠。进展保留至少一字段校验，交流保留对象及内容校验；补充字段折叠不会清空草稿。
- 未完成计划可移到操作日的明天或指定日期，保留 ID、createdAt 和其他字段；完成计划隐藏改期菜单。
- 跟进转计划以 sourceDiscussionId / sourceMentorActionId 唯一配对，同一事项重复操作打开已有计划。计划可返回原交流。删除来源交流或移除事项时解除来源，计划正文继续保留。
- 完成同步以用户最后编辑的一侧为准：计划完成对应跟进已完成，重新打开对应未处理；跟进未处理或处理中对应未完成计划，已完成对应完成计划。普通编辑、改期不会把处理中降为未处理。新完成设置完成时间，重开清空完成时间。
- 删除确认后显示 10 秒撤销提示，连续删除只保留最近一次撤销。撤销在当前列表合并恢复目标；不覆盖新记录、其他删除或更新后的正文。关联仅在受影响记录未被再次编辑且关联空缺时恢复。后续已编辑的记录保留其当前关联。原来源被重新转计划占用时，恢复旧计划但解除旧来源，避免重复。
- 删除、撤销或保存失败不修改内存中的已确认数据；撤销失败可重试。保存期间锁定操作，异常通过 finally 解锁，草稿保留；同一新草稿重试保留 ID 和创建时间。编辑旧记录不会补造缺失的 createdAt。
- 周报缺项提示只根据原记录空缺显示，补写直接编辑来源记录；提示不参与 Markdown 事实导出，原来源跳转继续保留。
- 导出备份升级到 v3，读取继续兼容 v1/v2。旧版本程序无法读取新 v3 备份。

验证使用 Flutter widget/domain 测试和 dart analyze；未构建 Web，未在 Android/iOS 真机验证平台语音、键盘或模糊渲染。
