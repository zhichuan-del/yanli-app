# 导师跟进与文件数据管理实施计划

目标：补齐用户确认的导师跟进、汇报文件和备份文件，以及清空确认和写入失败处理。

1. 为导师交流添加交流对象、下次交流日期、上次落实情况和多条独立状态的后续事项，兼容已有 next 文本和旧备份；测试存储往返及独立勾选。
2. 使用 Android 系统文件选择器导出 UTF-8 Markdown 汇报和 JSON 备份，选择文件后校验并确认恢复，保留既有复制、粘贴流程；取消和异常不得声称成功。
3. 保存操作串行执行，编辑器仅在写入成功后关闭；失败保留输入并允许重试。清空需要两次明确确认，未确认或写入失败不更新界面。
4. 汇报包含导师对象、已记录的上次落实情况及未完成后续，不推断事实；执行单元/组件测试、静态检查、安卓构建并说明真机验证范围。
