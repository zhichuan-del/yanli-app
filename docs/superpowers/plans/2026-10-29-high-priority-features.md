# 研历高优先级需求实施计划

根据用户指定修订版需求书，先为现有离线手机原型增加最常用、可安全迁移的功能。

1. 扩展计划优先级、计划时间、完成时间，科研进展类型及投入时间，旧版数据和备份继续可读；补充模型与数据往返测试。
2. 日历增加返回今天、计划/进展/导师交流的分类标识、按所选日期自然周计算完成率与进展数量；测试跨周和无计划情形。
3. 进展按关键词、时间范围和科研类型组合检索并可清空；进展填写要求至少有一条具体内容。
4. 汇报增加自选日期范围，保留真实来源、去重和未完成计划等已记录事项；页面可预览复制，保留原语音功能。
5. 验证完整测试、静态检查与安卓构建；报告尚未实现或未验证的需求，不覆盖已有安装包。
